# List<>

**_Qu'est-ce qu'une List en java_**

Ce sont des structures de données permettant de stocker des collections d'éléments, ordonnées et indexées.
List fait partie du framework Java Collections.
Les listes sont plus flexibles que les tableaux

**_Points essentiels :_**
- Les éléments sont accessibles par index, comme un tableau
- La taille est dynamique (vs les tableaux)
- Les doublons sont possibles
- L'ordre d'insertion est conservé


**_Implémentations principales (utilisée puisque List est une interface) :_**
- ArrayList (utilisées pour listes générales et lecture importante)
  Basée sur un tableau dynamique
  L'accès par index est rapide
  Ajout et suppression au milieu plus coûteux
- LinkedList (utilisées pour files, piles, manipulations fréquentes d'éléments)
  Basée sur une liste chaînée
  Accès par index plus lent
  Ajout et suppression rapides en début ou au milieu
(Remarque : Le choix de l'implémentation dépend du type d'opérations majoritaires, lecture vs insertion)

**_Méthodes les plus utilisées_**
add(element) => permet d'jouter un élément
size() => retourne la taille
contains(element) => vérifie la présence
get(index) => récupère un élément
set(index, element) => remplace un élément
remove(index) ou remove(object) => supprime
clear() => vide la liste

**__En résumé, Array vs List : __**


| Critère   | List |               Array |
| :--------- | :---------: | -----------------: |
| Taille     |    Dynamique    |     Fixe |
| Doublons |    Oui    | Oui |
| Accès par index | Oui | Oui |
| Ajout/suppression | Flexible | peu pratique |
| Syntaxe | Orientée objet | Syntaxe simple |
