

## 1. Qu'est-ce qu'une Interface ?
Une **interface** en Java est un mécanisme qui définit un "contrat" que les classes doivent respecter. Elle spécifie **ce qu'une classe doit faire**, mais pas **comment** elle doit le faire. C'est un outil fondamental pour le polymorphisme et l'abstraction. 

## 2. Définition et Implémentation 

On utilise le mot-clé `interface` pour la créer et `implements` pour l'utiliser dans une classe. 

```java
// Définition
 public interface Animal { 
 void crier(); // Méthode abstraite par défaut 
 void manger(); 
 } // Implémentation
 public class Chien implements Animal {
 
 @Override public void crier() { 
	 System.out.println("Ouaf !"); 
	 } 
 
 @Override public void manger() {
  System.out.println("Le chien mange des croquettes.");
   }
}
```

## 3. Caractéristiques principales

- **Méthodes abstraites :** Par défaut, toutes les méthodes d'une interface sont `public` et `abstract`.
    
- **Variables :** Toutes les variables déclarées dans une interface sont implicitement `public static final` (des constantes).
    
- **Héritage multiple :** Une classe peut implémenter **plusieurs interfaces**, contrairement à l'héritage de classe (une seule classe parente).

```java
public class Smartphone implements AppareilPhoto, Telephone, LecteurMusique {
    // Doit implémenter les méthodes des 3 interfaces
}
```

## 4. Évolutions (Java 8+)

Depuis Java 8, les interfaces ont évolué pour offrir plus de flexibilité :

### A. Méthodes par défaut (`default`)

Permettent d'ajouter de nouvelles fonctionnalités à une interface sans casser les classes qui l'implémentent déjà.

```java
public interface Vehicule {
    void rouler();
    
    default void klaxonner() {
        System.out.println("Tut tut !");
    }
}
```

### B. Méthodes statiques

Elles appartiennent à l'interface elle-même et non aux objets qui l'implémentent.

```java
public interface Calcul {
    static int addition(int a, int b) {
        return a + b;
    }
}
```

## 5. Interface vs Classe Abstraite

|**Caractéristique**|**Interface**|**Classe Abstraite**|
|---|---|---|
|**Héritage**|Une classe peut en implémenter plusieurs.|Une classe ne peut en étendre qu'une seule.|
|**Méthodes**|Principalement abstraites (sauf default/static).|Peut avoir des méthodes concrètes et abstraites.|
|**Attributs**|Uniquement des constantes (`static final`).|Peut avoir des variables d'instance classiques.|
|**Constructeur**|Impossible.|Possible.|


## 6. Pourquoi utiliser les interfaces ?

1. **Abstraction :** Masquer les détails d'implémentation.
 
2. **Découplage :** Réduire la dépendance entre les différentes parties d'un programme.

3. **Polymorphisme :** Manipuler différents types d'objets via une interface commune.
