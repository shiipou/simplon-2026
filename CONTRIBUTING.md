# 📜 Règles d'utilisation de ce dépôt GIT 📜

Voici les règles d'utilisation à respecter pour utiliser ce dépôt git de manière uniforme entre les apprenants.

## ✅ -  Écriture de la documentation en français

Le niveau en anglais des apprenants étant hétérogène, chaque documentation doit être écrite en français dans le but de la rendre pratique à utiliser pour chacun.

## ✅ -  Écriture des Pull Requests (PR) en anglais

Dans le but de s'entrainer en anglais, nous avons convenu de rédiger les Pull Requests en anglais.

## ✅ -  Respect du nommage des documents dans le README.md

Pour chaque dossier ou fichier nouvellement crée, veuillez respecter le nom déjà présent dans le sommaire du README.md afin de rendre votre travail accessible depuis la page d'accueil. 

> [!warning]
> En cas d'absence du nom de de vos documents dans le fichier README.md, il est à votre charge de les ajouter avant de faire votre PR.

## ✅- Convention de nommage des documents

Nous avons établi une convention de nommage pour nos documents, que vous retrouverez ci-dessous :
### 📂 Nommage des dossiers

Pour nommer les dossiers, Veuillez utiliser un nombre sur 2 caractères puis un point avant de mettre votre nom.

> [!note]
> Dans le cas ou plusieurs dossiers seront créés la même semaine, le nombre à mettre devant votre dossier vous sera donné pendant le sprint review.

## ✅- Faire les reviews avant de commencer une tâche 

Pour que le travail de chacun puisse arriver dans la branche `main`, il faut que chacun fasse les reviews disponibles avant de commencer une nouvelle tâche, de cette manière, les PR seront validées régulièrement.

## ❌ - Ne pas pousser de doc dans la branche main

Afin d'éviter tout conflit entre les documentations de chacun, nous avons décidé de créer une nouvelle branche pour chaque tâche. il est donc interdit de mettre ses documents sur GitHub via la branche `main`.
