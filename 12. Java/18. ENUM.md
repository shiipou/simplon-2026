# Le Type ENUM en Java

## 1. Qu'est-ce qu'un Enum ?

En Java, un `enum` (abréviation d'énumération) est un type de données spécial qui permet de définir une collection de **constantes nommées**. On l'utilise pour représenter un ensemble fixe de valeurs liées, comme les jours de la semaine, les directions cardinales ou les états d'une commande.

## 2. Définition de base

L'utilisation la plus simple consiste à déclarer une liste de valeurs.

```java
public enum Jour { LUNDI, MARDI, MERCREDI, JEUDI, VENDREDI, SAMEDI, DIMANCHE }
```

### Utilisation :

```java
Jour aujourdhui = Jour.LUNDI;

if (aujourdhui == Jour.LUNDI) {
    System.out.println("C'est le début de la semaine !");
}
```

## 3. Pourquoi utiliser des Enums ?

- **Sécurité de typage (Type Safety) :** Vous ne pouvez pas affecter une valeur autre que celles définies dans l'enum.

- **Lisibilité :** Le code est plus explicite que l'utilisation de constantes `int` ou `String`.

- **Namespace :** Les constantes sont regroupées sous le nom de l'enum.

## 4. Fonctionnalités Avancées

Contrairement à d'autres langages, en Java, les enums sont des **classes**. Ils peuvent donc avoir des attributs, des constructeurs et des méthodes.

### Exemple complet : Enum avec propriétés
```java
public enum Niveau {
    BAS(1),
    MOYEN(2),
    HAUT(3);

    private final int code;

    // Le constructeur est toujours privé par défaut
    Niveau(int code) {
        this.code = code;
    }

    public int getCode() {
        return this.code;
    }
}
```

## 5. Méthodes Intégrées

Chaque enum Java possède des méthodes pré-générées très utiles :

|**Méthode**|**Description**|
|---|---|
|`values()`|Retourne un tableau contenant toutes les constantes de l'enum.|
|`valueOf(String name)`|Retourne la constante correspondant au nom fourni.|
|`ordinal()`|Retourne l'index de la constante (commence à 0).|
|`name()`|Retourne le nom de la constante sous forme de String.|

### Exemple de boucle :

```java
for (Jour j : Jour.values()) {
    System.out.println(j + " est à la position " + j.ordinal());
}
```

## 6. Utilisation avec `switch`

Les enums sont parfaitement adaptés à l'instruction `switch`.

```java
switch (niveau) {
    case BAS:
        System.out.println("Niveau facile");
        break;
    case MOYEN:
        System.out.println("Niveau normal");
        break;
    case HAUT:
        System.out.println("Niveau difficile");
        break;
}
```
## 7. Points Clés à Retenir

1. **Instances Uniques :** Il n'y a qu'une seule instance de chaque constante (singleton).

2. **Comparaison :** On utilise l'opérateur `==` (au lieu de `.equals()`) car les instances sont uniques.

3. **Héritage :** Un enum ne peut pas étendre une autre classe (car il étend déjà implicitement `java.lang.Enum`), mais il peut **implémenter des interfaces**.

4. **Constructeur :** Il est toujours appelé lors de l'initialisation des constantes et ne peut jamais être appelé manuellement avec `new`.
